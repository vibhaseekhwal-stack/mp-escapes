# MP Escapes — Admin Panel

A premium, black + gold + white admin panel for the MP Escapes tourism platform, built with React, Vite and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser. Log in with any email/password — authentication is mocked for now (no backend is wired up).

## Build for production

```bash
npm run build
npm run preview
```

## Notes

- All data is dummy/mock data living inside each page/component file, exactly as scoped for this phase.
- No API/service files have been created — these will be added when backend integration begins.
- Colors, typography and layout follow the specified black (#0B0B0B) + gold (#C9A227) + white palette.
